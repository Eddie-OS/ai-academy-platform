AI学院联合作战平台 · 单机部署包
================================================================

这个包不需要 Docker，不需要安装 PostgreSQL，不需要管理员权限。
唯一的前置条件是一个 JRE 17（或 JDK 17）以上。

包里有什么
----------------------------------------------------------------
  app.jar        后端 + 内嵌 PostgreSQL 15（数据库二进制就在这个 jar 里）
  web/           前端页面，由 app.jar 同源托管
  start.ps1      启动
  hash.ps1       生成账号口令哈希
  .env.example   口令配置模板


三步装好
----------------------------------------------------------------
1) 确认 Java

     java -version

   显示 17 或更高即可。没有就先装 JRE 17。

2) 配两个账号口令

     copy .env.example .env
     .\hash.ps1

   按提示输入口令（不回显），把输出的那一行填进 .env 的
   OPERATOR_PASSWORD_HASH。再跑一次 hash.ps1，用另一个口令，
   填进 VIEWER_PASSWORD_HASH。

   两个账号不要用同一个口令：运营账号能写全部业务数据，
   用户账号只读。

3) 启动

     .\start.ps1

   首次启动要建库（initdb + 49 个迁移脚本），约 1～2 分钟，
   请勿中断。之后每次启动在 20 秒内。

   浏览器打开  http://localhost


日常运维
----------------------------------------------------------------
停止      在 start.ps1 的窗口里按 Ctrl+C

换端口    .\start.ps1 -Port 8080

日志      logs\app.log

数据      data\  这一个目录就是全部状态：
            data\pgdata\   数据库
            data\          上传的附件
          备份就是停掉服务、打包这个目录。恢复就是解回去。
          不要在服务运行时拷 data\pgdata（会拷到不一致的快照）。

演示数据  首次启动时如果 19 张业务表全空，会自动灌一份演示数据
          （598 行）方便验收。开始录真实数据前，把
          application-standalone.yml 里的 aiacademy.demo-data.enabled
          改成 false —— 或者直接不用管：只要库里已经有数据，
          这段逻辑整体跳过，不会覆盖任何东西。


出问题先看这里
----------------------------------------------------------------
启动脚本会在启动前逐项检查 Java 版本、交付物、口令哈希格式、
端口占用，不通过就不启动并说明是哪一项。按提示改即可。

浏览器一片空白        web/ 缺失或没打进包。接口本身是好的，
                      可以访问 http://localhost/swagger-ui.html 验证。

登录总是失败          .env 里的哈希不完整。BCrypt 哈希含 $ 符号，
                      确认粘贴时没被截断、没加引号，
                      末尾摘要应当是 53 个字符。

端口 80 被占用        .\start.ps1 -Port 8080

上次被强杀后起不来    删掉 data\pgdata\postmaster.pid 再启动。
