# 阶段 5　无障碍走查表（A11Y-01～30）

> 依据：设计基础规范 **§九**（阶段 5 文档误写「第 10 章」）。目标 WCAG 2.2 AA。
> 执行方式（开发 10.7）：对比度抽查 10 页；键盘走 E2E-1／E2E-6；`WarningLight` 全站复查。
>
> **本轮把「对比度」与「结构项」两类从手工勾选改成自动断言**，证据是可重跑的测试：
>
> | 覆盖面 | 测试 | 例数 |

> | 对比度（A11Y-01／01a／02／12） | `src/shared/theme/contrast.test.ts` | 7 |

## 兼容性（需求 16.1.6）

| 浏览器 | 1440×900 | 勾选 |
|---|---|---|
| Chrome 最新 | ☐ | 视觉回归跑在 Playwright 自带 Chromium（固定版本，见 `playwright.config.ts` 1.1） |
| Chrome 上一大版 | ☐ | |
| Edge 最新 | ☐ | 日志里出现过 Edg/151 的真实访问（`sys_login_log`），可作旁证但不算走查 |
| Edge 上一大版 | ☐ | |

> 四格仍是 ☐：自动化跑的是**固定版本的 Chromium**，刻意不跟随系统浏览器升级（否则基线会某天早上集体变红）。
> 因此「四个浏览器各开一遍」这件事自动化替代不了，必须人在验收机上点。

## 结论

- 自动化覆盖：**19 例新增断言全绿**（对比度 7 + 结构 12），加上既有组件测试
- 本轮修复的真实缺陷：**A11Y-29 页面标题、A11Y-30 跳过导航、重复 `<main>` 地标**（D5-8～D5-10）
- 待业务签字的书面例外：**A11Y-01a、A11Y-15**（新增两条），另有 V-4／V-5 与灯色豁免
- 其余 ☐ 共 8 条为人工走查项，完成后关闭 E5-2
