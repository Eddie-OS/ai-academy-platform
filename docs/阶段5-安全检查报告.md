## 1. 附件未登录直链（F3）

| 项 | 证据 | 结果 |
|---|---|---|
| 未登录下载附件（直连后端） | `smoke-test.ps1` 第 351 行：真上传一个 PNG，再用无 Cookie 会话打它的下载地址 | **401 `UNAUTHENTICATED`** |
| 未登录下载附件（**过 nginx**） | `GET http://localhost/api/attachments/1/download` 无 Cookie | **401 `UNAUTHENTICATED`** |
| nginx 是否把附件目录当静态资源露出 | `docker/web/nginx.conf` 只有 `/`、`/assets/`、`/api/`、`/actuator/health` 四个 location，root 指向前端 dist；探测 `/data/attachments/`、`/uploads/` 均落到 SPA 回落（`text/html` 387 字节的 index.html），**不是目录列表也不是文件** | 无静态旁路 |
| 已登录下载字节一致 | 同脚本，下载回来的字节数与首字节 `0x89` 都对得上 | 通过 |
| 临时签名 URL | `FileStorage` 鉴权下载，无永久公开链 | 代码审查通过 |

> 过 nginx 这一遍是本轮补的。只测后端 8080 有个盲区：**鉴权可能被反向代理绕过**——
> 只要 nginx 上多一个指向附件目录的 location，401 就形同虚设，而后端侧的测试全绿。

## 4. 日志脱敏（SEC4）

样本两份：本地 DEBUG 档 **6500 行**（今天跑过 5000 行导入、10000 行导出、200MB 上传与全套冒烟），生产同构栈 **442 行**（含两份历史归档）。

| 项 | 实测 | 结果 |
|---|---|---|
| 登录日志不含口令 | 本地 DEBUG 档 6500 行里 `password`／`口令`／`secret` 命中 **0 行**；`LoginLogMapper.insert` 的 SQL 与参数原文在 DEBUG 下完整可见，写的只有 `account_type / login_ip / user_agent / success` 四列。生产档那 18 行命中见本表最后一行 | 通过 |
| 工号批量 dump | 单行出现 ≥3 个工号的行数 **0** | 通过 |
| 会话与 CSRF 值 | `JSESSIONID`／`XSRF-TOKEN` 命中 **0 行** | 通过 |
| 生产档不打 SQL 参数 | 生产栈 442 行里 `Preparing:`／`Parameters:` **0 行**（`application-prod.yml` 把 `com.aiacademy` 定在 INFO）。本地档有 6374 行，是 `application-local.yml` 的 DEBUG 档，仅开发机 | 通过 |
| 启动守卫的报错是否泄漏哈希 | 生产档里 18 行命中 `password` 关键字，全部来自 2026-07-31 的 SEC5 口令哈希校验失败。报文只写**长度**（「长度 58，应为 68」）与修法提示，**不含哈希本身** | 通过 |

> 那 18 行值得单独说一句：它是「报错要有用又不能泄漏」两个要求同时被满足的例子。
> 只报长度就足以定位根因（`.env` 里 `$` 没转义被 Compose 插值吃掉），而把哈希打出来才是事故。
