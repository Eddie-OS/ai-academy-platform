# 运维手册

> AI学院联合作战平台 · 阶段 5 交付。生产环境：Windows 11 + WSL2 + Docker Desktop（BLOCK-05）。

## 1. 启动

```powershell
cd <仓库根>\ai-academy-platform
docker compose up -d          # postgres + app + nginx（生产 compose）
# 或本地开发：
docker compose -f docker-compose.local.yml up -d
cd backend; .\gradlew.bat :app:bootRun --args='--spring.profiles.active=local'
cd frontend; npm run dev
```

也可用 [`scripts/deploy.ps1`](../scripts/deploy.ps1)／[`scripts/build.ps1`](../scripts/build.ps1)。

健康检查：`GET http://localhost/actuator/health`（或 `:8080`）。

## 2. 停止

```powershell
docker compose down           # 不停数据卷
# 仅停 app 容器：
docker stop aiacademy-app
```

## 3. 备份

| 方式 | 说明 |
|---|---|
| 应用内定时 | `DatabaseBackupJob` 每日 02:00，`pg_dump -Fc` → `./data/backup`。**仅 Docker 形态可用** |
| 宿主机脚本 | [`scripts/backup.ps1`](../scripts/backup.ps1)：BK1～BK5（外置盘、附件 robocopy、失败写 status） |

注册计划任务示例见 `backup.ps1` 文件头注释。

### 单机形态（无 Docker）没有自动备份，只能手工

`DatabaseBackupJob` 调外部 `pg_dump` 可执行文件。Docker 形态下它在 postgres 容器里；
**单机形态下它不存在** —— 嵌入式 PostgreSQL 只解包 `initdb`、`pg_ctl`、`postgres` 三个程序，
交付包里既没有 `pg_dump` 也没有 `psql`。

所以 `application-standalone.yml` 里把 `aiacademy.backup.enabled` 显式设成了 `false`。
开着它的唯一效果是每晚 02:00 往日志里抛一次异常，同时让人以为备份已经配好 ——
那比明确没有备份更危险，因为只有真需要恢复的那天才会发现。

手工备份步骤：

1. 停掉应用（`start.ps1` 窗口按 Ctrl+C，或结束那个 java 进程）。
2. 把交付目录下的 `data/` 整个打包，例如
   `Compress-Archive -Path .\data -DestinationPath ..\backup-20260904.zip`。
3. 恢复就是停掉应用、把 `data/` 目录整个换回去。

**停机是必要的**：运行中的 PostgreSQL 数据目录直接复制可能拿到写入中途的不一致快照，
拷出来的文件看着都在、恢复时才发现起不来。附件与数据库都在 `data/` 下，
所以只需要打包一个目录（这是 `application-standalone.yml` 里刻意这么摆的）。

## 4. 恢复

按 [`备份恢复验证.md`](./备份恢复验证.md)：

1. 取最新 `.dump`
2. `createdb` 空库
3. `pg_restore --clean --if-exists`
4. 抽查 `biz_demand`／`dtl_escalation_record` 行数
5. 附件目录从备份盘对应路径拷回

**每月至少一次**真实恢复到临时库（BK3）。

## 5. 看日志

| 位置 | 内容 |
|---|---|
| Docker | `docker logs -f aiacademy-app` |
| 本地 bootRun | 控制台；`logging` 配置见 `application*.yml` |
| 任务运行 | 表 `sys_job_run_log` |
| 备份失败 Banner | `BACKUP_STATUS_FILE`（默认 `D:\aiacademy\backup-status.json`）→ 首页红条 |

## 6. 改配置

| 项 | 位置 |
|---|---|
| 数据库／口令哈希 | `.env`／`application-*.yml`（**勿提交明文生产口令**） |
| 附件根目录 | `aiacademy.storage.*`／`.env` `ATTACHMENT_DIR` |
| 备份目录 | `aiacademy.backup.dir` |
| 业务阈值／字典／催办 | **配置中心**（运营账号），勿直接改库 |
| Nginx 上传上限 | `docker/web/nginx.conf`（`client_max_body_size`，配合 200MB 分片） |

改完配置后重启对应容器／进程。业务侧保存配置会清进程内枚举缓存。
