# 阶段 5 · 产品动效设计实施文档

> 基线提交：`6dc8c038967b456f24f486a90c230a407b66b52b`
>
> 目标：在不改变业务口径、页面几何和视觉回归基线的前提下，为驾驶舱补充克制、可解释、可降级的产品反馈动效。

## 1. 设计定位

本平台属于高密度运营后台，动效只服务四类目的：

1. **状态可读**：打开、关闭、展开、筛选等状态变化不再硬切。
2. **数据可读**：指标与图表在首次呈现时建立数值层级。
3. **操作反馈**：hover、active、loading 等状态及时且一致。
4. **无障碍**：系统要求减少动态效果时，直接显示完整终态。

不采用品牌站动效：粒子、流体、3D、滚动叙事、磁吸按钮、持续脉冲、逐字标题、弹跳或弹性缓动。三色灯不增加闪烁或呼吸效果，颜色仍不是唯一信息载体。

## 2. 技术约束

- 只使用 CSS、Web Animations API 和现有 ECharts 5；不新增依赖。
- 主要动画只改变 `transform` 与 `opacity`，目标时长 120～240ms。
- 使用现有 `effectV2.transition = 120ms cubic-bezier(.2,0,0,1)` 作为微交互基准。
- 页面在去掉全部动画后仍须完整、可读、可操作。
- `prefers-reduced-motion: reduce` 下直接进入终态，不保留隐藏元素。
- Playwright 打开 `?fixture=1` 时关闭全部新增动画，截图几何和像素基线不变。
- 人眼打开同一地址不再关动效；系统「减少动态效果」仍关。本地强制预览用 `?motion=1`。
- 焦点环立即出现，不做动画；不通过改变边框宽度表达状态。

## 3. 实施范围与顺序

### P0 · 全局 reduced-motion 与 ECharts 降级

1. 提供统一的动态偏好判断函数，供 React/图表逻辑使用。
2. ECharts 在视觉回归模式或减少动态效果模式下统一设置 `animation: false`。
3. 复用并核验 `tokens.css` 已有的 reduced-motion 后备规则，压缩遗漏的 animation/transition 时长。
4. 增加单元测试，覆盖普通模式、回归模式和 reduced-motion 模式。

验收：减少动态效果时图表直接呈现最终图形；页面无不可见内容。

### P1 · 详情面板 open / close / expand 过渡

1. 面板首次挂载：`opacity + translateX(8px)` 进入，时长 160ms。
2. 点击关闭：反向淡出后执行原 `onClose`；不支持 WAAPI 或处于降级模式时立即关闭。
3. 标准宽度与展开宽度切换：详情列宽度与面板阴影使用统一 120ms 过渡。
4. 所有 Ant Design Modal/确认框/Drawer 使用统一进入与退出节奏；V2 自绘课程、需求、
   试讲日历和讲师字段弹窗通过 `useDialogMotion` 延迟 140ms 卸载，保证退出帧真正播放。
5. 视觉回归与 reduced-motion 模式均直接显示终态。

验收：不影响详情深链、列表选中态、sticky 定位和展开后的表格宽度。

### P2 · KPI 数字 roll-up 与卡片 stagger

1. V2 默认页的 KPI 卡首次呈现时按 70ms 间隔依次进入；旧业务轨的 `MetricCardRow`
   仍按 40ms 间隔进入。
2. 新增共享 `AnimatedNumber`：只对可安全解析的数值执行 0→目标滚动；百分比、小数和千分位保持原格式。
3. 九张 V2 默认页全部接入 `AnimatedNumber`；`—`、非数值文案不做伪造动画；
   reduced-motion 与回归模式直接显示终值。
4. ECharts 继续使用自身动画，不叠加第二套图表时间线。

验收：零值显示 `0`；无数据显示 `—`；卡片宽高、换行和数字格式不变。

### P3 · 组件八态的微交互补全

优先覆盖共享入口，不批量改写 Ant Design 内部实现：

- 可点击指标卡：hover 阴影/边框反馈，active 下压 1px。
- 详情面板图标按钮：沿用 Ant Design 的 default/hover/focus/active/disabled/loading。
- hover 仅在 `@media (hover: hover) and (pointer: fine)` 下启用。
- `focus-visible` 使用即时 outline，保持键盘可见性。

验收：default、hover、focus-visible、active、disabled、loading、error、success 由 Ant Design 与项目补充样式共同覆盖；不得出现 bounce/elastic。

### P4 · 导入/表单用户触发的派生数字

1. 导入预览由用户选择文件并提交后返回，属于用户触发的派生结果。
2. 预览中的总行数、错误数、警告数使用共享 `AnimatedNumber` 短时滚动。
3. 页面初始加载、历史批次列表和非用户触发刷新不执行 count-up。
4. 动画只改变文本值，不移动布局；为最终值预留宽度。

验收：错误报告下载、问题表分页和导入提交逻辑不变。
