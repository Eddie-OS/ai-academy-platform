第 1 条最值得留意：它不是风格问题。待催办清单少匹配一个状态的症状是**「该催的人没出现在清单里」**，界面上看不出异常，运营也不会发现——而 E4-1 的五维度对数恰好是按当时数据对的，对得上不代表转换表改名后还对得上。

第 4 条是纪律问题：扩功能时顺手改了冻结数据。冻结数据存在的意义就是不随功能变动，扩页签只能追加记录。

第 5 条不是阶段 4 引入的（讲师页本阶段一行未动），顺手修掉：`LecturerV2Page.css` 里
`.lct-sub-title` 与 `.lct-ledger-head` 两条覆盖跟 `panel.css` 的 `.panel-title` / `.panel-head`
**特异性相同**，谁生效只看两份 CSS 在打包产物里的先后，而 `panel.css` 排在后面——标题行高仍是
28px、间距仍是 12px，两处合计 10px 把表格顶出区域。改成 `.panel-title.lct-sub-title` /
`.panel-head.lct-ledger-head`（`DemandV2Page.css` 已有同款写法），并把表头 26→24、行高 22→20
把 129px 的表格收进 178px 的区域。**这类失效不报错、不告警，只有几何断言能抓到。**
