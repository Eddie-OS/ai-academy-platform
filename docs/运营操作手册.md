# 运营操作手册

> 面向运营账号日常操作。截图位标「【截图】」，上线前由实施人员补图。

## 登录

1. 打开平台地址，使用 **运营账号** 登录。  
2. 用户账号看不到「导入中心」「配置中心」侧栏——这是权限设计，不是故障。

## 一、六类导入

入口：侧栏 **导入中心**。

| 类型 | 用途 | 注意 |
|---|---|---|
| 人员 | 人员台账 | 离职状态影响负责人警告 |
| 签到 | 场次签到 | 须已有场次号；最常用 |
| 讲师 | 讲师池 | 依赖人员已存在 |
| 参训名单 | 场次名单 | — |
| 学员反馈 | 挂场次 | 场次须已开课／已结束／已归档 |
| 试讲反馈 | 挂试讲 | — |

### 标准步骤

1. 下载对应模板（含「填写说明」第二 sheet）。也可使用冻结包 [`import-templates/`](./import-templates/README.md)。  
2. 按说明填表，**不要改表头**。  
3. 上传 → 等待校验报告。有错误则整批拒绝，下载错误报告改正后重传。  
4. 校验通过后 **确认入库**。  
5. 单文件不超过约 5000 行（超限后端拒绝）。

### 导错了怎么撤销

1. 在导入批次列表找到该批次。  
2. 执行 **撤销**（破坏性操作，有二次确认）。  
3. 该批次写入的行按快照还原／逻辑删除；**不是**再导一次覆盖。

## 二、催办怎么记

系统 **不发送** 微信／邮件／站内信，只生成「该催谁」的清单并记台账。

1. 打开 **消息中心**（侧栏名；内容是催办台账）。  
2. 在待催办清单勾选对象，可改文案。  
3. 点击 **标记已催办** → 写入台账。实际通知在平台外完成。  
4. 同一对象 **24 小时内**再次标记会提示，确认后可强制记录。

## 三、配置中心（勿随意改）

五个 Tab：三色灯阈值／字典／任务派生规则／自检题库／催办配置。  
改阈值后灯色 **实时重算**，无需重启。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 「该记录已被他人修改」 | 他人用同一运营账号改过；刷新后重试（乐观锁） |
| 红灯改了错别字还不消失 | 正常：红灯只看状态变更时间 |
| 用户账号不能导入 | 正常：仅运营可写 |
